如何用 Python 抓取网页

抓取网页分三步：下载、解析、转换。第一步最容易被低估，因为它涉及网络、编码和反爬。

一、下载

用 requests.get() 发一个 HTTP GET 请求。记得设置 timeout，否则程序可能永远卡住。

  • 状态码 200 表示成功
  • 404 表示页面不存在
  • 403 通常是被反爬拦了

二、解析

HTML 是一棵树。用 BeautifulSoup 把它变成能按标签查找的对象。

提示：不要在网页上改代码。

三、转换

最后用 markdownify 把节点翻译成 markdown。结果应该是一份能直接读的文档。

python main.py https://example.com/post
